The size of a matrix is written as number of rows X number of columns
Matrix A: Has 2 horizontal rows and 3 vertical columns so its size is 2 X 3
Matrix B: Has 3 horizontal rows and 2 vertical columns . 3 X 2



In Aij or Bij notation the first number represents the row number , and the second number represents the column number
A12: The entry in row 1 , column 2 of matrix A = -1
A23 : The entry in row 2 , column 3 of matrix A = 5
B21 : -2
B32 : 1



Second row of A: ( 0  4  5 )
First column of B: ( 1 )
                   (-2 )
                   ( 4 )
